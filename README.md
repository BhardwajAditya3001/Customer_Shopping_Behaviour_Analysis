# Customer_Shopping_Behaviour_Analysis
🛍️ Customer Shopping Behaviour Analysis  


📌 Overview  

This project analyzes customer shopping behavior using transactional data from 3,900 purchases to uncover insights that support data-driven business decisions. It focuses on identifying spending patterns, customer segments, and product performance to improve marketing and revenue strategies.

📊 Dataset
* Records: 3,900
* Features: 18
* Includes customer demographics, purchase details, and behavioral data (discount usage, frequency, ratings, shipping type)
* Missing Values: 37 (handled using median imputation)

⚙️ Tech Stack
* Python (Pandas): Data cleaning
* SQL: Business analysis using SQL
* Power BI: Interactive dashboard & visualization

🔍 Workflow
* Cleaned and preprocessed data in Python
* Loaded data into SQL for structured querying
* Built Power BI dashboard to visualize insights

📈 Key Insights
* Male customers contribute ~68% of total revenue
* Express shipping users spend more per transaction
* Subscription users show high loyalty (~91% repeat purchases)
* Majority (~82%) customers are loyal repeat buyers
* Certain products consistently receive higher ratings

💡 Business Recommendations
* Promote subscription models to increase retention
* Implement loyalty programs for repeat customers
* Optimize discount strategies for better margins
* Focus marketing on high-value customer segments
* Highlight top-performing products in campaigns
